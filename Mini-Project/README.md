# YouTube Trending Videos Analytics & Category Insights

## 📊 Project Overview

YouTube Trending Videos Analytics & Category Insights is a collaborative Team Mini Project developed as part of a Data Analysis learning journey.

The project aims to analyze trending YouTube videos across 10 countries and explore video performance, category popularity, channel performance, and audience engagement.

Using Microsoft Power BI, the project transforms raw data into an interactive dashboard that helps users explore trends, compare performance, and gain meaningful insights from YouTube trending video data.

---

## 🎯 Project Objectives

- Analyze YouTube trending videos across multiple countries.
- Identify top-performing videos and channels.
- Compare video performance across different categories.
- Analyze audience engagement through views, likes, and comments.
- Explore trending patterns over time.
- Build an interactive dashboard using Microsoft Power BI.
- Apply data cleaning, data modeling, and data visualization techniques.

---

## 📁 Dataset

The project uses the YouTube Trending Videos dataset, covering 10 countries.

The original dataset consists of 20 files:

- **10 CSV files:** Contain trending video records for each country.
- **10 JSON files:** Contain video category metadata for each country.

## 📈 Dashboard Pages

The Power BI dashboard consists of seven pages.

### 1. Home
Provides the project introduction and navigation to the dashboard.

### 2. Overview
Presents an overall view of video performance through key performance indicators and visual summaries.

### 3. Category Analysis
Explores category popularity and compares performance across different video categories.

### 4. Channels & Top Videos
Analyzes top-performing videos and channels using performance metrics.

### 5. Time Analysis
Explores trending patterns and changes in video performance over time.

### 6. Engagement
Analyzes audience engagement using views, likes, and comments.

### 7. Video Details
Provides detailed information about individual videos to support more focused analysis.

## 🔍 Key Analysis Areas

The project focuses on the following analytical areas:

- **Video Performance:** Understanding video performance through views and other available metrics.
- **Category Insights:** Comparing the performance of different video categories.
- **Channel Analysis:** Identifying channels associated with high-performing videos.
- **Audience Engagement:** Exploring likes, comments, and views.
- **Time-Based Analysis:** Investigating changes in trending video performance over time.
- **Key Performance Indicators:** Using DAX measures to calculate and present important metrics.
